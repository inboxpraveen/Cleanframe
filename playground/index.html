                How is this scored?
                
The Mess Score is 100 minus CleanFrame's quality score, the same deterministic number cleanframe report prints. Each problem adds a penalty of severity weight × share of rows affected (error 1.0, warning 0.4, info 0.1; a problem without a count assumes 25% of rows). Exact duplicate rows add 0.5 × their share. The total is averaged over the columns:

                

                
Detectors inspect up to the first 50,000 non-empty values of each column. It is a heuristic for "is this file getting better?", not a benchmark.

      How it works
      
      
      CleanFrame is an open-source Python library. This page runs the real thing, the same code as pip install cleanframe-engine, with the deterministic rules planner (no AI, no API keys).
      
      
      
        
      01 · Detect
      Find the mess
      Thirteen detectors look for mixed date formats, misspelled categories, money stored as text, stray whitespace, disguised nulls, invalid emails and phones, duplicates and more.
      
        
      02 · Plan
      Write a recipe
      Every fix becomes a line of YAML: readable, diffable, yours to edit and commit. Problems that need a human are flagged, not silently "fixed".
      
        
      03 · Replay
      Run it forever
      cleanframe apply replays the recipe on next month's file with plain pandas, and stops on schema drift. Or export the generated pandas code and keep no dependency at all.
      
      
      
    
      
  
      

  
      
    
      
      
      
        
      Your data stays on this device
      
        
      Not a promise in a privacy policy: it is how the page is built.
      
        
        
          
      • Python runs in this tab. CPython, pandas and CleanFrame are compiled to WebAssembly (Pyodide) and run in a background thread. Your file is read into that thread's memory and nowhere else.
        • 
          
      • Two origins, enforced. A Content-Security-Policy lets the page fetch only from this site and the pinned Pyodide directory on jsDelivr. Any other connection, including one that tried to send your data away, is blocked by the browser.
        • 
          
      • No tracking. No analytics, cookies, fonts or third-party scripts.
        • 
          
      • Check it yourself. Open your browser's developer tools, go to Network, and drop a file: no request carries your data.
        •
